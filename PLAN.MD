Build a meeting agenda

Layout = vertically arranged time slices
A new slice can be created with an Add button located at the top. The new time slice gets inserted at the top.
Time slices can be easily edited or deleted.
Each time slice contains: Role, User Name, Duration (in Minutes)
Time slices can be reordered through drag and drop.
There should be an enabled/disabled toggle that grays out the time slice. That way, slices can be disabled and re-enabled later without deleting and re-adding.

Time slices can be nested within other time slices. This should happen if a time slice is dragged directly onto another time slice. For example, there may be an Introduction section that contains multiple other slices where individuals get up to introduce themselves.

A control should allow the selection of the starting time from 12:00 to 11:30 at increments of 30 minutes (no need to specify AM or PM)
On the right, there should be a timeline that starts at the starting time and adds the number of minutes for each time slice. The goal is to show the time when each speaker is scheduled to start and finish. Disabled time slices should not have their time added to the timeline.
